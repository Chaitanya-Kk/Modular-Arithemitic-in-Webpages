How Modular Arithmetic
Runs the Web

Discover the mathematical elegance powering your digital experience. From secure logins to infinite scroll, explore 10 fundamental concepts that make the modern web possible.

1

Divisibility & Modular Arithmetic

📊 Session IDs / Order Numbers
user_id = 1234567
bucket = user_id % 1000 # → 567

→ Shards users across 1000 database partitions for horizontal scaling

→ Masks true user count for security (rate-limiting, analytics)

2

Division Algorithm

📄 Pagination
page = Math.floor((index - 1) / pageSize) + 1;
offset = (page - 1) * pageSize;

→ totalItems = quotient × pageSize + remainder

→ Enables "Page 3 of 57", infinite scroll, and efficient SQL queries

3

Primes

🔒 SSL/TLS Handshake (RSA, ECDHE)

→ 2048-bit primes generate public/private keys

→ Prime-based Diffie-Hellman ensures forward secrecy

→ Even if server is compromised later, past sessions stay safe

4

GCD & Euclid's Algorithm

🖼️ Responsive Image Grids
g = gcd(1920, 1080) # → 120
ratio = f"{1920//120}:{1080//120}" # → "16:9"

→ Reduces aspect ratios to simplest form

→ Consistent CSS grids, avoids pixel distortion in images

5

Extended Euclid's Algorithm

✍️ RSA Digital Signatures (JWT, OAuth)
d = mod_inverse(e, φ(n)) # private key from public (e, n)

→ Verifies signature^ e ≡ hash(message) (mod n)

→ Used in GitHub SSH, Apple Pay, bank logins

6

Fundamental Theorem of Arithmetic

🎲 Unpredictable Session Tokens

→ Token = large random number factorized only by server

→ Unique prime factorization = no two users get same token

→ Brute-force resistant security

7

Congruences

🔗 URL Shorteners (bit.ly, tinyurl)
id = database_row_id
short_code = base62_encode(id % 62^6)

→ hash(input) ≡ consistent_value (mod table_size)

→ Maps billions of URLs to 6–8 char codes

8

Fermat's Little Theorem

🔐 Primality Testing in TLS
if a^(p-1) ≡ 1 (mod p) for random a
→ p is *probably* prime

→ Used in OpenSSL to pre-validate large primes

→ Fast, secure HTTPS setup during key generation

9

Euler's Totient Function φ(n)

🔑 RSA Key Generation
φ(n) = (p-1)(q-1)
public_exponent e ∈ {x | gcd(x, φ(n)) = 1}

→ Defines valid public keys (usually 65537)

→ Determines encryption strength for PCI-DSS compliance

10

Chinese Remainder Theorem (CRT)

📈 Distributed Analytics (A/B Testing)
total_clicks ≡ 105 (mod 8) # server A
total_clicks ≡ 13 (mod 7) # server B
total_clicks ≡ 21 (mod 5) # server C
→ CRT solves: total_clicks = 805

→ Combines sharded counters exactly without double-counting

→ Accurate dashboards at scale
